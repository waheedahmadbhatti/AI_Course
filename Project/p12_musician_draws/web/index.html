How Air Harp Works

1
Allow camera — the page uses your webcam to track both hands in real time.
2
Pinch to draw — touch thumb + index on both hands; a glowing line stretches between them.
3
Release to save — strings ≥ 80 px are saved (max 8). Longer strings play lower notes.
4
Pluck to play — swipe an index fingertip across a string. It wobbles and plays a note.

About Air Harp

A browser-based virtual harp that turns your hands into strings. Built with MediaPipe Hands for real-time hand landmark tracking, the Web Audio API for synthesized notes (sine + 2nd harmonic with exponential decay), and HTML Canvas for the glowing, vibrating string visuals.

No data leaves your device — the camera feed is processed locally in your browser.
